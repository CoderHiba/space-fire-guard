# 🔥🚀 Space Fire Guard

**A smart educational app that compares fire behavior in space and on Earth to protect lives.**

## 📖 About the Project
Space Fire Guard is an interactive app designed to teach users about fire safety. It uses real scientific data from NASA experiments (FLEX, BASS-II, Cool Flames) to show how fire behaves differently in microgravity compared to Earth. 

The app helps users understand **if a material will catch fire** based on oxygen levels, and **what to do** if a fire breaks out in different environments (Kitchen, Forest, Lab, or Space Station).

## ✨ Features
*   **Space Library**: Explore 3 NASA experiments (FLEX, BASS-II, Cool Flames) with simple explanations.
*   **Fire Risk Calculator**: Select a material (wood, plastic, fabric) and oxygen level (21%, 30%, 40%) to see if it's 🟢 Safe, 🟡 Warning, or 🔴 Dangerous.
*   **Solutions**: Get practical advice on how to extinguish fires in different environments.
*   **Earth vs. Space**: Compare how the same material burns in a kitchen vs. a space station.

## 🛠️ Built With
*   **Kotlin Multiplatform (KMP)** - Share logic across platforms.
*   **Compose Multiplatform** - Build UI once and run on Android, iOS, and Desktop.
*   **Jetpack Compose** (for Android UI).

## 🚀 How to Run
1. Clone the repository.
2. Open the project in IntelliJ IDEA or Android Studio.
3. Select your target (Android emulator or Desktop).
4. Click Run.
